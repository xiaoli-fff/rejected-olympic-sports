One line, read with a straight face: Synchronized Queueing — four athletes, one post office, zero eye contact, judged on patience, passive aggression, and who sighs loudest at the ticket machine.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
